# QR Code Generator & Designer

Free, no-backend QR code generator and designer. Supports URL/text, WiFi,
vCard, and email content types, with customizable dot styles, corner
styles, colors/gradients, 11 frame styles, a logo, and a live contrast
checker for scannability. Runs entirely client-side.

## Development

```
npm install
npm run dev
```

## Build

```
npm run build
```

Output goes to `dist/`, deployed automatically to GitHub Pages by
`.github/workflows/deploy.yml` on every push to `master`.
